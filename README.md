## О проекте

KURO FINANCE — лёгкий виджет в стиле "ночного города": тёмная тема по умолчанию, минимум элементов, пять рабочих зон.

Код-нейм **Kuro** — в честь японского *"чёрный"* (黒). Черный чай, ночные покатушки и ровная аналитика по деньгам.

> **v1.0.2** — актуальный релиз. Скачать: [GitHub Releases](https://github.com/Ta4erOK/kuro-finance/releases)

## Возможности

### 💸 Траты
- Ввод трат по категориям — категории создаёшь сам, под себя
- Комментарий и дата к каждой трате
- **Редактирование и удаление** любых записей
- Навигация по дням: вчера, позавчера — всё под рукой
- Итоговая сумма за день снизу

### 🏦 Копилка
- Фиксируй, сколько положил на счёт сегодня
- Общая сумма накоплений — всегда перед глазами
- **Цели копилки** с прогресс-барами (например «на машину»)
- История пополнений по дням с редактированием

### 💳 Долги
- Учёт долгов: кому и сколько должен
- **Погашения с историей платежей** и общим прогрессом
- Остаток долга всегда в шапке приложения

### 📊 Статистика
- Периоды: **день / неделя / месяц / год**
- Суммы и **процентное соотношение** трат vs накоплений
- Графики по дням и месяцам (Chart.js)
- Диаграмма по категориям — куда утекают деньги
- Средние траты в день, дни с тратами
- **Сводка по 12 месяцам года**
- **Сравнение этого месяца с прошлым**
- Сводка за текущий месяц прямо в шапке

### ⚙️ Настройки
- **Месячный доход** — видно % от дохода
- **Лимит бюджета** на месяц — полоска в шапке (зелёная → жёлтая → красная)
- Управление категориями: добавление, переименование, изменение цвета
- **Виджет-режим**: компактное окно поверх всех окон
- **Сворачивание в трей** при закрытии окна
- **Напоминание вечером** — в указанное время напомнит записать траты
- **Светлая и тёмная тема**
- **Автозапуск** с Windows (по умолчанию выключен)
- **Бэкапы**: ручной + автоматический раз в неделю

## Запуск (development)

```bash
# 1. Установка зависимостей
npm install

# 2. better-sqlite3 — нативный модуль, пересборка под Electron
npx electron-rebuild -f -w better-sqlite3

# 3. Запуск (vite dev server + electron)
npm run dev
```

## Сборка установщика (Windows)

```bash
npm run build:win
```

Готовый установщик появится в папке `release/` — `kuro-finance-setup-1.0.2.exe`.

> Подпись кода отключена (`signAndEditExecutable: false`) — winCodeSign падает на симлинках без прав администратора. Windows может показывать «неизвестный издатель» при установке.

## Данные

База данных — SQLite (`finance.db`).

| Режим | Расположение БД |
|:---|:---|
| Development | Корень проекта: `finance.db` |
| Production | `%APPDATA%/FinanceWidget/finance.db` |

БД создаётся автоматически при первом запуске. Авто-бэкапы и резервные копии складываются в папку `backups/`.

## Иконка

Иконка рисуется из `build/icon.svg` скриптом `npm run gen:icons`. Тёмный градиент, ночной полумесяц и зелёный график роста — для тех, кто копит, а не спускает.
